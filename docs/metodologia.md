# Metodologia

O projeto segue o fluxo:

Dados sintéticos → SQL → EDA → GLM de frequência → GLM de severidade → Prêmio puro →
Prêmio comercial → Retenção/elasticidade → Estratégias de pricing → Monte Carlo →
Capital econômico → RoC/EVA → Decisão.

A documentação técnico-pedagógica completa será consolidada após a estabilização do repositório.
