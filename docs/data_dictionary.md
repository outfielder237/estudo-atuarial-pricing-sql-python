# Data Dictionary

## apolices.csv
- `id_apolice`: identificador sintético da apólice
- `exposicao`: exposição em anos
- `idade_condutor`: idade do condutor
- `idade_veiculo`: idade do veículo
- `regiao`: região geográfica sintética
- `tipo_veiculo`: categoria do veículo
- `tipo_uso`: particular ou comercial
- `nivel_cobertura`: nível de cobertura
- `classe_bonus`: classe de bônus
- `premio_vigente`: prêmio anual vigente sintético
- `premio_ganho`: prêmio ganho no período

## sinistros.csv
Contém os sinistros sintéticos associados às apólices, incluindo identificadores e valor de sinistro.
