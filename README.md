# Data

This project uses a fully synthetic automobile insurance portfolio created for educational purposes.

- `apolices.csv`: synthetic policy-level data.
- `sinistros.csv`: synthetic claim-level data.
- `pricing.db`: generated SQLite database used by the analysis scripts.

No file in this folder should be interpreted as real insurer, SUSEP or Brazilian market data.
The database can be regenerated by running Stage 02.
