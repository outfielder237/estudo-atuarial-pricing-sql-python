# Data

Este projeto utiliza uma carteira de seguro automotivo totalmente sintética, criada para fins educacionais.

- `apolices.csv`: dados sintéticos em nível de apólice.
- `sinistros.csv`: dados sintéticos em nível de sinistro.
- `pricing.db`: banco de dados SQLite gerado e utilizado pelos scripts de análise.

Nenhum arquivo nesta pasta deve ser interpretado como dados reais de seguradora, da SUSEP ou do mercado brasileiro.
O banco de dados pode ser regenerado executando a Etapa 02.
